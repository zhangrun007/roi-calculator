# 🧮 ROI 保本测算器 · 通用版

电商投放 ROI 保本测算工具（纯前端 / 单文件 / 离线可用）。

- **18 项成本要素**全部手动填写：售价、优惠券、件数、产品成本、包装礼盒、快递、运费险、平台扣点、品牌授权、税点、达人佣金、商务提成、坑位费、退款率、发货前退占比、退货运费、投流 ROI
- **实时输出**：毛利率、保本 ROI、单均净利、成本明细、成本结构图、ROI 1~6 档净利表
- **两种退货口径**：精简（实收×退款率）/ 精细（拆发货前后退）
- 数据不上传，纯浏览器本地计算

> 口径：`保本ROI = 实收 ÷ 毛利 = 1 ÷ 毛利率`（成交/消耗）
> 注意另一口径 `成本 ÷ 毛利 = 1/毛利率 − 1`，数值低 1.0，勿混用。
